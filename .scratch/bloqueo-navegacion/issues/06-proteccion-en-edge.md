# 06: Protección en Edge

**What to build:** Edge aplica las reglas de dominio y ruta de Locky y activa el bloqueo del escritorio ante una página prohibida. La navegación InPrivate queda deshabilitada.

**Blocked by:** 01: Primer bloqueo en Chrome; 02: Reglas de dominio y ruta.

**Status:** ready-for-agent

- [ ] Una página prohibida no carga en Edge y activa la página de bloqueo.
- [ ] Una página permitida carga; las reglas de ruta no bloquean el resto del sitio.
- [ ] InPrivate no puede abrirse durante el uso protegido de Edge.
- [ ] Las reglas consolidadas se aplican de nuevo tras cerrar y abrir Edge.
