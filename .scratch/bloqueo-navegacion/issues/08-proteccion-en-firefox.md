# 08: Protección en Firefox

**What to build:** Firefox aplica las reglas de dominio y ruta de Locky y activa el bloqueo del escritorio ante una página prohibida. La navegación privada queda deshabilitada.

**Blocked by:** 01: Primer bloqueo en Chrome; 02: Reglas de dominio y ruta.

**Status:** ready-for-agent

- [ ] Una página prohibida no carga en Firefox y activa la página de bloqueo.
- [ ] Una página permitida carga; las reglas de ruta no bloquean el resto del sitio.
- [ ] No se puede abrir una ventana privada durante el uso protegido de Firefox.
- [ ] Las reglas consolidadas se aplican de nuevo tras cerrar y abrir Firefox.
