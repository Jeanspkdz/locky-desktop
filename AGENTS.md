# Project instructions

## Package manager

- Always use `pnpm` to install, update, or remove JavaScript dependencies.
- Run package scripts with `pnpm run <script>` or `pnpm <script>`.
- Use `pnpm dlx` instead of `npx` when appropriate.
- Keep dependency locking in `pnpm-lock.yaml`.

## Agent skills

### Issue tracker

Issues and specs are local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context glossary and ADRs. See `docs/agents/domain.md`.
