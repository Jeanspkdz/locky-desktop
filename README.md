# Locky Desktop

Aplicación local para Windows que permite bloquear sitios web elegidos por la persona usuaria. Las reglas se administran desde el escritorio y se aplican mediante extensiones de navegador.

## Desarrollo

```powershell
pnpm install
pnpm start
```

Para ejecutar las pruebas: `pnpm test`.
